# Pop Defense

An original balloon-popping tower defense game written in plain HTML, CSS and JavaScript. No libraries are used, and every graphic is drawn in code.

**Play:** https://georgelloydd.github.io/btd/

## Features
- 3 maps: Meadow Loop, Zigzag Canyon and Frozen Spiral
- 3 difficulties (Easy, Medium, Hard), plus freeplay after you win
- 8 towers, each with 2 upgrade paths of 3 tiers (only one path can reach tier 3)
- 13 balloon types, including lead, camo, ceramic and blimps
- Targeting modes, 1x/2x/3x speed, auto-start and saved best rounds

## Controls
| Key | Action |
|---|---|
| Q W E R T Y U I | Pick a tower |
| Click | Place or select a tower (hold Shift to keep placing) |
| Space | Start the round or change speed |
| , and . | Upgrade path 1 or path 2 |
| Tab | Change targeting |
| S | Sell |
| P | Pause |
| Esc or right-click | Cancel |
